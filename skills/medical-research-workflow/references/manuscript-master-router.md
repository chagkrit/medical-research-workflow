# Manuscript Master Router

Use this router when a task goes beyond drafting a medical manuscript and asks for development, peer review, language refinement, journal targeting, reviewer response, or submission readiness.

## Modes

### A. Develop

Use `references/manuscript-master-develop.md` when the user asks to improve, restructure, strengthen, diagnose, rewrite, or prepare a revision plan for a manuscript.

Outputs:

- Document-readiness snapshot.
- Critical risk list.
- Development route.
- Revision blueprint.
- Section-level rewrite or revision plan.
- Reviewer-response strategy when reviewer comments are supplied.

### B. Evaluate

Use `references/manuscript-master-peer-review.md` when the user asks for peer review, pre-submission audit, checklist review, self-audit, formal reviewer-style critique, or readiness assessment.

Outputs:

- Manuscript type decision.
- Executive evaluation.
- Core checklist table.
- Method-specific add-on assessment.
- Priority revision roadmap.
- Submission recommendation.

### C. Language Refine

Use `references/manuscript-language-refiner.md` when the user asks for academic English polishing, naturalness, journal-style tone, deep humanization, or section-specific language refinement.

Outputs:

- Revision intent.
- Refined version.
- Change notes.
- Integrity check.

Never alter scientific meaning, citations, data, methods, or claim strength without flagging the change.

### D. Journal Strategy

Use `references/journal-strategy.md` when the user asks which journal to submit to, whether a target journal fits, Q1/Q2 strategy, desk-reject risk, Plan A/B/C, writing culture, or journal-specific style.

Outputs:

- Journal requirement map.
- Fit assessment.
- Competitive positioning.
- Desk-reject risk scan.
- Writing culture decode.
- Plan A/B/C submission strategy.
- Action checklist before submission.

Verify current journal scope, article types, fees, indexing, acceptance requirements, and author instructions from official journal/publisher pages before making final recommendations.

### E. Full Pipeline

Use all four modules in order when the user asks for end-to-end manuscript support:

1. Quick triage from Develop.
2. Peer evaluation from Evaluate.
3. Revision blueprint from Develop.
4. Language risk check from Language Refine.
5. Journal strategy from Journal Strategy.
6. Integrated action list with the top three actions before submission.

## Medical Research Guardrails

- Keep `medical-research-workflow` as the governing workflow for clinical/statistical validity.
- Use `statistical-judgment.md` before interpreting analysis results.
- Use `citation-integrity.md` and `citation-search-strategy-expanded.md` for citations.
- Use reporting guideline modules before manuscript submission.
- Do not let language polish hide methodological weakness.
- Do not let journal strategy drive overclaiming or selective reporting.
