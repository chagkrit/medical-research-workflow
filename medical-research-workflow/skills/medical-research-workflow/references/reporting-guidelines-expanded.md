# Reporting Guidelines Expanded

Use this module when aligning manuscripts, abstracts, tables, and submission checklists with study design.

Verify the current checklist from the official source before submission.

## CONSORT

Use for randomized trials.

Check:

- Trial design and allocation ratio.
- Participants, settings, eligibility.
- Interventions with enough detail for replication.
- Prespecified primary and secondary outcomes.
- Sample size calculation.
- Random sequence generation, allocation concealment, blinding.
- Participant flow.
- Recruitment dates and follow-up.
- Intention-to-treat or per-protocol handling.
- Harms/adverse events.
- Registration and protocol access.

## STROBE

Use for cohort, case-control, and cross-sectional studies.

Check:

- Design in title/abstract.
- Setting and dates.
- Eligibility and selection.
- Variable definitions and data sources.
- Bias and confounding handling.
- Study size rationale.
- Missing-data handling.
- Descriptive data and outcome/event counts.
- Main and sensitivity analyses.
- Generalizability.

## STARD

Use for diagnostic accuracy studies.

Check:

- Participant selection and sampling.
- Index test and reference standard details.
- Blinding.
- Time interval between tests.
- Indeterminate/missing test results.
- Cross-tabulation of index test by reference standard.
- Accuracy estimates with uncertainty.

## TRIPOD / TRIPOD-AI

Use for prediction model development/validation.

Check:

- Source of data.
- Participants and outcomes.
- Predictors and measurement timing.
- Sample size and missing data.
- Model specification.
- Internal/external validation.
- Discrimination, calibration, and clinical utility.
- Full model availability.

## Reporting Precision

- P values: report exact values unless very small; avoid `p=0.000`.
- Confidence intervals: always include effect estimate and interval.
- Percentages: include numerator/denominator.
- Decimal places: use clinically sensible precision consistently.
- Label analyses as adjusted, unadjusted, weighted, imputed, sensitivity, exploratory, or post hoc.
